## 1 · ABLATION — every node clickable, switchable, tweakable

**His ruling on validation:** the strongest test he can run alone,
without showing anyone anything, is removing a system and checking the
deficit is the one the science predicts.

- EVERY NODE ON THE MIND MAP IS CLICKABLE. A menu on the node:
  turn it OFF, turn it back ON, and tweak the few settings that
  system owns.
- THE PREDICTIONS ARE THE TEST. Take the attention door out and it
  should be OVERWHELMED, not stupid. Take consolidation out and it
  should learn but not RETAIN. Each ablation is a testable claim about
  what the science says that system does, written before the switch is
  flipped.
- A DISABLED SYSTEM IS VISIBLE AS DISABLED — dark on the map and named
  in the health panel, never confusable with a system that is simply
  idle.
- COSTS NOTHING AND NEEDS NOBODY. It runs on his bench, on his own
  time, and it is validation no peer reviewer could give him.

## 2 · REPRODUCE HUMAN FAILURES, NOT ONLY SUCCESSES

A mind built on real science should make the ERRORS the science
documents. Each of these has a published curve to check against:
- OVEREXTENSION — a child calls every animal "dog" before it narrows.
- THE VOCABULARY SPURT — a crawl, then a burst around 18-24 months.
- PRIMACY AND RECENCY — the first and last of a list recalled best.
- SOURCE MONITORING FAILURE — an imagined event misremembered as real.

If the mind reproduces a curve nobody built in, that is validation.
If it does not, that is a finding. Either way it is worth having.

## 3 · ACCIDENTAL VALIDATION — log it when it happens

**It has already happened once.** The morning the model was not
running, the mind kept its needs, its drives and its body while
thought went dark — brainstem intact, cortex gone. A real
neurological state, reproduced by an architecture nobody told about
it, because the layers were built where the biology puts them.

When that happens again it is recorded here as evidence, with what was
observed and what science it matched.
